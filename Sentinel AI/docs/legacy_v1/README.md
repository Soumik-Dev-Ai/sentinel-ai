# Sentinel AI v1.0 Legacy Documentation Archive

This folder archives the original v1.0 specifications of Sentinel AI (authored July 2026), when the project was implemented as a single-agent ReAct (Reason + Act) prototype with a terminal CLI/HTML log viewer.

## Archived Documents
1. **`PRD_v1.0.md`**: Initial specification for the ReAct loop, single-agent working memory, and failure taxonomy (F1–F5).
2. **`ARCHITECTURE_v1.0.md`**: System architecture for `AgentRunner`, `WorkingMemory`, and static HTML viewer.
3. **`TECH_STACK_v1.0.md`**: CLI runtime dependencies (`rich`, `jinja2`, `anthropic`, `openai`).
4. **`TESTING_PLAN_v1.0.md`**: Initial test harness covering unit tests for ReAct steps and failure modes.
5. **`IMPLEMENTATION_ORDER_v1.0.md`**: Step-by-step checklist for building the v1 prototype.
